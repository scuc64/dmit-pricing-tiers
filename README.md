# DMIT 价格：从年付 $36.9 到月付 $1009.9，洛杉矶、香港、东京三条线路的套餐差价与按预算选型思路

搜 DMIT 价格的人，多半撞上过同一件事：同一款 LAX.Pro.STARTER，这家写 $29.9/月，那家写 $34.9/月，还有一家写 $38.9 甚至 $43.9/月。这几个数字都不是编的——它们分别对应 AMD EPYC 7003（AS3）、9004（AN4）、9005（AN5）三个硬件平台上同一档配置的标价。

DMIT 的定价表看着乱，是因为它不是一条曲线，而是“机房 × 线路 × 硬件平台 × 计费周期”四层叠出来的结果。把这四层拆开，价格就没那么难读了。

## 先搞清楚这四个变量

**机房**决定基准水位。洛杉矶（LAX）、香港（HKG）、东京（TYO）三地，同一个入门配置，香港最贵，洛杉矶最便宜。

**线路**决定第二层差价。Premium（Pro）走 CN2 GIA，旗舰档；Eyeball（EB）回程走 CMIN2 与 AS9929，带宽给得更大、价格低一档；Tier 1（T1）是纯国际线路，不对中国大陆做优化，同机房最便宜。

**硬件平台**决定同一个套餐名下的浮动。AS3 用 EPYC 7003，定位长期性价比线；AN4 用 EPYC 9004，是过渡产品，官方说明里明确写了“不再扩容、售完为止”，并且计划上调新购价格；AN5 用 EPYC 9005，性能最好，也最贵。

**计费周期**决定最终实付。月付最贵，季付、半年付、年付依次往下走，再叠加优惠码。

## 计费周期和优惠码，能把实付价压下来多少

DMIT 的周期越长越便宜，部分平台（例如 AN4）年付按 9 折计算。优惠码则是按“线路 + 周期”绑定的，用错适用范围就是零效果。以下几组码在多个独立来源里被反复记录过：

- `LAX-EB-LAUNCH-NON-MONTHLY-RECURRING-20OFF`：洛杉矶 EB 线，TINY 及以上，非月付订单 8 折，循环折扣
- `Lite-Annually-Recur-30OFF` / `Lite-Semi-Annually-Recur-20OFF`：Standard/Lite 网络，年付 7 折、半年付 8 折
- `202510_HKG_TYO_PRO_20OFF_RECURRING`：香港与东京 Pro 线，季付及以上 8 折

用法都一样：选好套餐和周期，在结算页填码后点 Validate Code 验证，能减多少当场就显示出来。这些码都有时效，看不到折扣就说明已经失效，别硬填。

另外还有一批以 2025-XMAS 开头的节日码在聚合站上被反复转载。从命名方式就能看出来它们绑定的是当时的活动，指望长期有效不现实。DMIT 也放过按客户状态分档的折扣（已有对应机房在用订单的用户折扣更大，新客折扣略小），以及半年付、年付送 1.3 倍流量的活动。这类活动的共同点是窗口很短，看到就当周决定。

## 按预算挑：四种常见需求对应的价格档

**预算 $40/年以内，只要一个海外 IP**：洛杉矶 AS3 的 T1.WEE 或香港 T1.WEE，都是 $36.90/年。别指望大陆访问速度，这个价位买的是端口和流量。

**预算 $10～15/月，主要给大陆用户访问**：洛杉矶 Pro 线的 TINY。选 AS3 平台 $10.90/月，选 AN5 平台 $14.90/月，差价买的是 CPU 代差。注意入门两档最低季付。

**流量优先、访问质量够用就行**：洛杉矶 EB 线。同样大约 $10/月的预算，AN4 EB.TINY 给 1500GB 流量，比 Pro 同价位多 500GB。移动网络用户的体验尤其接近 Pro。

**必须香港节点**：HKG.Pro.TINY $39.9/月起，或者退一步选 HKG.T1 的 $6.90/月档，代价是大陆方向没有专门优化。

**高配需求（多核、大内存、10Gbps 端口）**：从 AN5 Pro 的 MINI 到 GIANT，$79.90～$1009.90/月。这一段可以按 EPYC 代际往下找同规格的 AN4、AS3 档位省钱，但要接受它们后续调价或停售的可能性。

## 看价格之外，下单前要确认的几件事

**超量不等于停机。** 洛杉矶 Pro 与 EB 在流量用尽后限速到 4～10Mbps 继续跑，T1 限速到 100～500Mbps。这决定了你是“超了就被扣费”还是“超了就慢”，DMIT 属于后者。

**流量按双向计算。** 上传和下载都计入月流量额度，拿它当大文件中转站的话，实际可用量会比标称值少一截。

**库存波动比价格波动更频繁。** 热门低价档位经常处于缺货状态，同一档位在不同时间点的在售情况也不一样。价格与库存以下单页面实时显示为准。

**调价不影响已有订阅。** 官方说明过，硬件与价格调整不会改变正在运行服务的续费价，只有主动升级规格时才按新价格执行。这一点对打算长期续费的人比较关键。

**支付方式。** 支付宝、PayPal、信用卡都可以，国内用户不需要额外折腾外币渠道。

DMIT 的价格表不适合一次性背下来，因为它每一季都在改。真正需要记的只有一句：先确定机房，再确定线路，最后在 AS3/AN4/AN5 里选平台——同配置的三个价，差价买的就是这三层选择的组合。
